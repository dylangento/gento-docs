Gento Teleoperation Apex 是适用于 Marvin Pro、Skye 和 Luna 的 VR 遥操作系统。操作员通过 VR 头显看到实时第一视角画面，动作以低延迟映射到机器人。Apex 还可录制机器人数据与视频用于示教数据集，并提供 ROS 2 接口供二次开发。Manus 数据手套配合 Wuji Hand 为选配。

## 从哪里开始

| 机器人 | 入口 |
| --- | --- |
| Marvin Pro 当前版本（天准控制器） | 先完成[接线](../marvin-pro/wiring.mdx)，再按 [Marvin Pro：首次遥操作](./marvin-pro.mdx)操作 |
| Marvin Pro 早期版本（Orin 控制器） | [Marvin Pro 早期版本（Orin）](../marvin-pro/earlier-orin.mdx) |
| Skye 或 Luna | [Skye 与 Luna：首次遥操作](./skye-luna.mdx) |

安装、检查或升级软件，参见[安装与升级 Apex](./setup.mdx)。机器人控制器每次上电后，请先[启动相机](../software/cameras.mdx)再开始遥操作。

## 软件分层

Apex 上位机软件用于连接机器人控制器、管理遥操模块、切换控制模式、查看相机画面，以及录制、回放和排查运行日志。交付软件由机器人控制端、Teleop 遥操服务和前端界面组成，三者版本号含义不同。

| 软件层 | 当前文档基线 | 作用 |
|---|---|---|
| Marvin Pro 控制端 | `gento-apex 1.1.7.1` | 当前 Pro 源码核对目标，使用 Gento SDK `4.7.1`；源码中仍标记为未正式发布 |
| Skye/Luna 控制端 | `v1.0.6.95g-beta-10-g14cfc0d` | 当前 Gento 源码核对快照；客户安装包以交付清单为准 |
| Teleop 遥操服务与前端 | 随交付批次配套 | 处理遥操数据并提供上位机界面，不与控制端包版本混用 |
| 头显客户端 | 随交付批次配套 | 提供视频显示和遥操输入 |

版本会持续更新，以上编号用于说明当前文档基线，现场应使用同一交付批次的配套软件。

## VR 头显

:::warning 有线头显接线
头显连接天准控制器时使用 **1 号网口**，连接灵境 Thor 控制器时使用 **2 号网口**；两种控制器的默认连接地址均为 `6.6.7.100`。现场网络参数如有调整，以设备交付配置为准。
:::
