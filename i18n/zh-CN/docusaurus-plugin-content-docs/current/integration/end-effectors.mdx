机械安装、供电、通信和软件集成应分别确认。具有法兰适配器，不代表已经完成遥操作或数据录制支持。

## 集成检查

| 范围 | 针对具体末端工具确认 |
| --- | --- |
| 机械 | 法兰图纸、适配件、紧固件、工具包络和线缆间隙 |
| 电气 | 电压、电流、引脚定义及外部供电要求 |
| 通信 | 设备协议、总线配置及匹配驱动 |
| 动力学 | 工具质量、质心和惯量配置 |
| 控制 | 指令映射、限位及控制权交接 |
| 录制 | 可用信号、时间戳及同步 |

## 源资料

## 工具动力学

Pro 手册介绍空载和带载轨迹采集、工具质量/质心/惯量计算及参数设置。这些流程会引起运动，必须使用正确构型和辨识轨迹，不属于初学者安装步骤。

末端供电电压因机械臂配置而异，请勿直接按通用产品表选择。连接灵巧手或相机前，请确认交付机械臂的电气接口。
