:::danger 安装前
机器人必须固定牢固后才能接通电源。请勿安装或运行有损坏、零部件缺失的机器人。请在机器人外围设置安全栏并明确标识动作区域。
:::

## 开箱检查

到货后对照装箱清单确认内容。安装多台机器人时，确认机器人和控制器编号一致，否则可能误动作。

## 搬运

- Marvin 双臂总质量（含包装，不含底座）为 16–26 kg。短距离搬运需多人协作，不推荐单人搬运。
- 机器人底座约 130 kg，禁止人工搬运，请使用专业搬运工具。
- 长途运输前将机器人调整至装箱姿势，并使用专用纸箱包装。
- 搬运时避免过度振动和冲击。吊装、叉车等作业须由持证或经授权人员进行。

## 存放与环境

存放温度为 -10 ~ 60 ℃，无凝霜。安装场所应满足：

- 室内，避免阳光直射
- 远离灰尘、油烟、盐分、铁屑，以及易燃或腐蚀性液体和气体
- 运行时环境温度 0 ~ 45 ℃，湿度 20 ~ 80 %RH（无结露）
- 振动加速度不大于 4.9 m/s²（0.5G）
- 远离强磁场、电磁源（如 TIG 焊接设备）和电气干扰源
- 海拔 1000 m 以下

在接近 0 ℃ 的环境中长时间停机后再启动，可能因驱动部阻滞而报警。此时以 25% 速率暖机 10 分钟。

## 零点姿态与零点标定

使用前确认机器人零点姿态与说明书图 2-1 一致；如不一致，请联系 Gento 技术支持。

出厂时已完成零点标定，日常使用无需标定。以下情况需要重新标定：

- 更换了关节驱动器或整个关节
- 重新安装系统或更换控制器硬盘
- 发生剧烈碰撞后

## 固定手臂

手臂基座有 11 个安装孔。推荐紧固件如下：

| 项目 | 推荐规格 |
| --- | --- |
| 螺钉 | 内六角圆柱头螺钉 M4×14（GB/T 3098.1-2010，12.9 级） |
| 垫圈 | 无压纹锥形弹簧垫圈（JIS B 1251-2018 2L-4） |
| 紧固扭矩 | 4.8 N·m |
| 数量 | 11 |

- 安装面平面度须在 0.05 mm 以下，否则可能损坏底座或影响性能。
- 将机器人基座背面槽口与安装支架背面槽口对齐。
- 地基须能承受静态负荷及手臂运动产生的反作用力。
- 手臂完全展开时，腕部工具或工件不得碰到墙壁或安全栏。
- 定位螺栓、定位销、底板等安装零件由客户自备。
- 本系列支持任意角度安装，固定方式相同。壁挂或倒挂安装请先联系 Gento，并做好防坠落措施。
- M3-SRS/CCS 与 M6-SRS/CCS 底座一致，安装方式相同。

M6、M3 底部安装尺寸见说明书图 2-3、图 2-4。
