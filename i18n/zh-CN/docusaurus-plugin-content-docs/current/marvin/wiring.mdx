:::warning 接线前
外部接线只能由经过培训并获得授权的工程师进行。通电前检查电压等级、线序和绝缘，设备须可靠接地。在 Power LED 指示灯熄灭后再进行接线和检查。请勿触摸手臂基座内部的关节模组器件。
:::

## 系统组成

Marvin 双臂系统由机械臂、控制器模块（选配）、电源模块（选配）、机器人支撑架（选配）和机器人底座（选配）组成，接线示意见说明书图 3-1。

选配的延长管线包、电源线、EtherCAT+485 线和末端 8Pin 插头线仅用于调试。正式集成时，请根据说明书提供的线缆规格、连接器和端子型号设计适合的线缆。未选配控制器模块时不提供延长管线包。

## 手臂电源

| 项目 | 规格 |
| --- | --- |
| 供电 | DC48V ±20% |
| 功耗（单臂，M6） | 典型 300 W，峰值 600 W |
| 过压报错 | 供电电压超过 58 V |
| 欠压报错 | 供电电压低于 30 V |
| 连接器 / 端子 | HRS DF63W-2EP-3.96C / DF63-1618PCF |
| 线缆 | 双绞线 AWG18 |

选配电源模块为明纬 RSP-2000-48 开关电源。

## 控制器电源

控制器主板功耗 20 W，供电 DC12V。控制器有两个供电接口，接其中一个即可：

| 接口 | 用途 | 规格 |
| --- | --- | --- |
| 供电接口 1 | 电源适配器（主板装在控制器盒中时使用） | 景赛 SG-120400050A，DC12V 4A |
| 供电接口 2 | 开关电源 | Molex 5557-04R 连接器、5556T 端子，AWG22 双绞线 |

## 泄放模块

手臂在高转速、大负载下会产生再生能量，泄放模块和制动电阻用于消耗这部分能量，避免母线过压报错停机。

- 使用开关电源供电时，建议使用泄放模块。
- 使用电池为手臂供电时，可不使用泄放模块。

接线见说明书图 3-7。

## EtherCAT 与调试 485

每条手臂基座预留 EtherCAT 插头和调试 485 插头，EtherCAT 连接控制器，调试 485 通过 USB 转 485 线连接上位机 DriveMaster2.0，用于关节驱动调试和固件升级。

| 线束标签 | 手臂 |
| --- | --- |
| 485A-L / 485B-L | 左臂 |
| 485A-R / 485B-R | 右臂 |

EtherCAT+485 线：HRS DF62W-6EP-2.2C 连接器，AWG24 双绞线；RJ45 端为 8P8C。USB 转 485 调试线需自备。

## 末端 8Pin 接口

| 引脚 | 定义 |
| --- | --- |
| 1 / 2 | DC24V 供电输出，额定电流 3 A |
| 3 / 4 | 485 通道 1 |
| 5 / 6 | 485 通道 2 |
| 7 / 8 | CAN，默认 CAN FD |

末端插头为威浦 SF810B/P8，线缆 AWG26×4P。末端法兰另有拖动按钮，用于拖动示教。

## 上位机调试网口

控制器网口 1（ETH1）和网口 3（ETH3）均可用于上位机调试，控制器默认 IP 为 192.168.1.190。调试网线需自备。连接方法见[连接上位机](./first-connection.mdx)。

## 急停

控制器急停插头为 JST RF-10，端子 RF-SC2290，AWG24 线缆。安装时注意方向，请勿插反。

:::warning 停止类别
说明书中的急停接线属于 1 类停止。如需 0 类停止，请根据相关技术规范自行设计。
:::
