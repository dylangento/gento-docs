以下日常操作均在电脑上通过网络完成。请先[连接用户电脑](./connect-pc.mdx)，并确认能 ping 通机器人。

如需启动或查看相机，参见[启动与查看相机](./cameras.mdx)。

Windows 10/11 可在 PowerShell 中使用 `ssh`，Ubuntu 可在任意终端中使用。首次连接某台机器人时，输入 `yes` 信任该设备。

## 连接 Orin 或 Thor

Marvin Pro、Luna 和 Skye 的 AI 控制器（NVIDIA Orin 或 Thor）地址为 `6.6.7.100`。以 `nvidia` 用户登录，密码见机器人随附资料。

- **终端：** `ssh nvidia@6.6.7.100`
- **远程桌面：** 使用 [NoMachine](https://www.nomachine.com/download) 连接 `6.6.7.100`。

### 无显示器使用 NoMachine

Orin 或 Thor 未连接显示器时，NoMachine 会出现黑屏。如需在无显示器的情况下远程连接，请先通过 SSH 登录，再执行：

```bash
sudo systemctl stop display-manager
sudo /etc/NX/nxserver --restart
```

然后重新用 NoMachine 连接。该设置在 Orin 或 Thor 重启后失效，每次上电后需重新执行。

## 查看 Apex 遥操作版本

Apex 机器人端软件包运行在 Orin 或 Thor 上。登录（`ssh nvidia@6.6.7.100`）后执行：

```bash
dpkg -l kernelmind-apex
```

输出的最后一行为 `kernelmind-apex` 软件包：行首 `ii` 表示已安装，第三列为版本号。如提示 `no packages found matching kernelmind-apex`，说明该电脑未安装 Apex。升级前请记录版本，并使电脑端应用和头显 APK 与之匹配（参见[安装 Apex 遥操作](../teleoperation/setup.mdx)）。在 Ubuntu 操作电脑上执行同一命令，可查看电脑端应用的版本。

## 查看控制器固件版本

x86 运控控制器在控制服务启动时会打印固件版本。选择匹配的 [Marvin Platform 编译脚本和 SDK](../marvin-pro/compatibility.mdx) 时需要用到该版本。

如果 Marvin Platform 已能连接机器人，其窗口底部会显示控制器版本，无需重启，参见[连接与读取状态](../marvin-pro/first-connection.mdx#确认实时反馈)。否则，请按以下步骤重启控制服务。

:::warning 此操作会重启运控控制器
`stop.sh` 会停止控制器。执行前请将机械臂下使能，确认没有软件在控制机器人，并确保急停按钮触手可及。
:::

1. 以 `root` 用户登录 x86 控制器，密码为 `passwd`。

   | 机器人 | 命令 |
   | --- | --- |
   | Marvin Pro、Luna、Skye | `ssh root@6.6.7.190` |
   | Marvin | `ssh root@192.168.1.190`（1003 固件）或 `ssh root@6.6.7.190`（1004 固件） |

2. 重启控制服务：

   ```bash
   cd /home/FUSION/Shell
   ./stop.sh
   ./start.sh
   ```

3. `start.sh` 会打印固件版本。记录版本号后输入 `exit` 退出。

## 无法登录时

| 提示信息 | 检查项 |
| --- | --- |
| `Connection timed out` 或 `No route to host` | 电脑不在机器人网络中，参见[连接用户电脑](./connect-pc.mdx)。 |
| `Permission denied` | 用户名或密码错误。Orin/Thor 使用 `nvidia`，x86 控制器使用 `root`。 |
| NoMachine 黑屏 | Orin 或 Thor 未连接显示器，参见[无显示器使用 NoMachine](#无显示器使用-nomachine)。 |
| `REMOTE HOST IDENTIFICATION HAS CHANGED` | 之前连接过同一地址上的另一台机器人。执行 `ssh-keygen -R 6.6.7.100`（或所用地址）后重新连接。 |
