Marvin Platform 是用于配置机器人、监视反馈和操作控制器运动功能的上位机。9 月中文软件指南描述其支持 Linux x86 和 Windows 64 位平台。

## 源指南中的编译脚本

| 指南中的控制器标识 | Windows 脚本 | Ubuntu 脚本 |
| --- | --- | --- |
| “41” | `marvinSDK_windows.bat` | `marvinSDK_ubuntu.sh` |
| “43” | `marvinSDK_windows_100343.bat` | `marvinSDK_ubuntu_100343.sh` |

指南将 `ui_EN.py` 列为 SDK 编译后的上位机入口文件。使用脚本前，请先[查看控制器固件版本](./cameras-firmware.mdx)、[确认机械臂型号并设置配置文件](./sdk-quickstart.mdx)，并确认仓库修订版。参见 [SDK 入门](./sdk-quickstart.mdx)。

## 在 Linux 上运行 Marvin Platform

Marvin Platform 需要 Python 3.10 及以上版本和 Pillow（`pip install pillow`）。在 SDK 根目录下：

1. 编译动态库。脚本会编译 `libMarvinSDK.so` 和 `libKine.so`，并复制到 `SDK_PYTHON` 和 `DEMO_C++`。控制器为“41”时，请改用 `marvinSDK_ubuntu.sh`。

   ```bash
   chmod +x marvinSDK_ubuntu_100343.sh
   ./marvinSDK_ubuntu_100343.sh
   ```

2. 安装 Microsoft 核心字体。Marvin Platform 使用 Arial 字体，缺少该字体时 `ui_EN.py` 会报 TrueType 字体错误。安装程序提示时，请接受字体许可协议。

   ```bash
   sudo apt install ttf-mscorefonts-installer
   ```

3. 启动 Marvin Platform：

   ```bash
   cd MarvinPlatform_EN
   python3 ui_EN.py
   ```

| 提示信息 | 解决方法 |
| --- | --- |
| 启动 `ui_EN.py` 时报 TrueType 字体错误 | 安装字体（第 2 步）后重新运行 `ui_EN.py`。 |
| `No module named 'tkinter'` | `sudo apt install python3-tk` |
| `No module named 'PIL'` | `pip install pillow` |

## 反馈字段

![Marvin Platform 反馈界面](/img/marvin-pro/platform-feedback.webp)

| 字段 | 软件指南中的含义 |
| --- | --- |
| Position | 电机端编码器转换得到的关节角度 |
| Velocity | 关节速度 |
| Torque | 扭矩传感器反馈 |
| Current | 关节额定电流的千分比 |
| Temperature | 温度；Pro 手册提醒此字段可能随版本变化 |
| PositionEX | 减速机输出端编码器转换得到的关节角度 |
| CmdPosition | 关节指令位置 |
| ForceEST | 各关节外部负载估计值 |

扭矩传感器反馈与外部负载估计是不同数据。该界面中的电流数值不是直接以安培表示。用于录制或控制之前，请核对 SDK 中的单位和消息定义。
