Marvin Pro 是用于操作、遥操作和数据采集的固定式双臂平台。两条机械臂各有 7 个关节，共 14 个自由度，不包含末端执行器。胸腔和头部均为固定结构。

![Marvin Pro 双臂平台：绿色、蓝色与灰色](/img/marvin-pro/colors.webp)

## 系统组成

![Marvin Pro 固定支架与一体化电箱](/img/marvin-pro/product.webp)

| 组件 | 作用 |
| --- | --- |
| 双力控机械臂 | 位置控制与阻抗控制操作 |
| 固定支架与一体化电箱 | 机械支撑、供电与接口连接 |
| 头部及腕部相机 | 环境观测与近距离操作视角 |
| 机器人端计算单元 | 按配置运行 Apex 服务、相机采集与录制 |
| 上位机应用和 VR 头显 | 配置、操作与遥操作 |

产品折页列出的 M6 配置单臂额定负载为 6 kg，工作半径为 696 mm；M6 Lite 配置分别为 5 kg 和 615 mm。两者属于不同配置，参数不可混用。
