安装或运行前，请阅读随设备交付的完整手册。本页整理 Pro 手册中的环境条件和使用前检查，不替代完整安全说明。

## 安装环境

| 条件 | Pro V1.0 手册要求 |
| --- | --- |
| 场所 | 室内，避免阳光直射 |
| 工作温度 | 0–45°C |
| 相对湿度 | 20–80%，无结露 |
| 海拔 | 低于 1,000 m |
| 振动加速度 | 低于 4.9 m/s²（0.5 g） |

远离灰尘、油烟、盐分、铁屑、易燃或腐蚀性物质、强磁场和电气干扰。超出上述条件的环境，请先咨询 Gento。

## 到货及姿态检查

检查磕碰、变形、缺件及型号不符等情况。将初始姿态与手册示意图比较；不一致时，请先联系支持。下图是姿态参考，不是要求机器人运动的指令。

![交付手册中的零点姿态参考图](/img/marvin-pro/zero-posture.webp)

## 运动前

确认随机急停已连接、工作区域已清空，并核对末端工具和机器人配置。绿色指示灯或软件已连接，不代表工作区域已经安全。使用运动模式前，先阅读[控制模式限制](../software/control-modes.mdx)。
