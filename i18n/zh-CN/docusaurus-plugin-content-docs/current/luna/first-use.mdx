## 开箱检查

用随货提供的密码打开包装箱密码锁，移除挡板，手动将机器人推出，然后确认以下物品齐全：

- 轮式双臂机器人本体 ×1
- 底盘遥控器（手柄）×1
- 以太网线缆 ×1
- 电源线及手动充电器
- 磷酸铁锂电池 ×2
- 遥操头显套件
- DB9 调试线缆 ×1
- 产品合格证与保修卡

如发现物品缺失或外观损坏，请立即联系销售代表或技术支持，切勿通电使用。

## 每次启动前检查

1. 整体结构完好，连接部件、机械臂、轮组及末端执行器无松动、变形或损坏
2. 急停按钮能可靠触发和释放
3. 电池电量满足作业需求，电源连接正常
4. 控制终端或遥操作终端无故障报警、通信异常或系统错误提示
5. 未安装未经授权的硬件、软件或第三方附件
6. 周围环境满足安全运行条件

## 开机与连接手柄

1. **插入电池**：将电池限位轨道对准小车限位槽，垂直插入两块电池。
2. **开机**：按下底盘下方的电源开关，亮起绿光即开机完成。
3. **连接手柄**：将手柄公头插入车尾的手柄母头，连接成功后手柄绿灯闪烁。
4. **手柄开机**：长按 Home 键。
5. **切换 D 模式**：同时长按 "+" 和 "-" 两次。第一次后第一个灯常亮，第二次后三个灯常亮，即进入 D 模式。
6. **出仓**：底盘初始速度为 0.6 m/s，按主控盘后退方向键将机器人移出包装仓。

## 手柄按键

| 按键 / 摇杆 | 功能 |
| --- | --- |
| 主控盘（方向键） | 控制底盘前后左右移动 |
| 摇杆 A | 同主控盘 |
| 摇杆 B | 控制底盘原地旋转 |
| RT 键 | 长按加速 |
| 充电口 | 手柄底部，用于为手柄充电 |

## 移动底盘

![Luna 全向移动底盘](/img/luna/chassis.webp)

1. 确认机器人周围无人员和障碍物。
2. 按方向键或推动摇杆 A 前后左右移动；推动摇杆 B 原地转向。
3. 需快速移动时长按 RT 键；松开按键后底盘停止。

:::warning 首次驾驶
首次操作请低速移动，熟悉操控后再逐步加速。确认急停按钮位置，紧急情况下立即按下。
:::

| OTA 升级失败 | 红色常亮 | — |

## 充电

| 方式 | 说明 |
| --- | --- |
| 手动充电 | 专用充电器（IP65，CC/CV 多阶段充电）。连接电池后将电源接口插入底盘接口，呼吸灯变为黄色 1 Hz 闪烁。注意插头方向。 |
| 智能移动充电桩回充（选装） | 自动回充启用、电量低于阈值且无任务时，机器人自动导航至充电站对接充电。需先完成充电桩安装调试，并在地图中配置充电站。 |
| 独立电池充电仓（选装） | 离线充电与快速换电。AC 90–240 V 输入，适用 48 V 电池系统，充满自动停止。 |
