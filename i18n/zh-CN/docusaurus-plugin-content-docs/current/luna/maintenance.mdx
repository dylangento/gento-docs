## 维护项目与周期

| 项目 | 内容 | 推荐周期 |
| --- | --- | --- |
| 外观检查 | 检查有无明显损坏、磨损和磕碰 | 每日 |
| 外观清洁 | 用干净、干燥的软布清洁，避免水分和侵蚀性清洁剂 | 每日 |
| 急停功能测试 | 确认急停可靠 | 每日 |
| 紧固件检查 | 检查并紧固所有螺钉和连接件 | 每日 |
| 电气连接检查 | 确认电气连接牢固，无虚接或损坏 | 每月 |
| 软件数据备份 | 备份关键软件配置和数据 | 每月 |
| 传感器和器件检查 | 确认传感器及关键器件工作正常 | 每月 |
| 软件更新 | 检查并更新控制软件和应用程序 | 每次更新时 |
| 固件更新 | 检查并更新固件 | 每次更新时 |

保修条款以说明书和购买合同为准。未经书面授权擅自拆卸、改装或维修将导致保修失效。

## 使用过程中的安全要求

1. 始终在额定载荷范围内运行，禁止超负载作业。
2. 按末端执行器的设计用途操作。
3. 在平整地面运行；跨越坡面时坡度不超过 10°。
4. 运动过程中不要推拉、碰撞或阻碍机器人。
5. 非专业人员不得修改运动控制参数或关闭主动安全保护功能。
6. 出现异常运动、碰撞风险或其他紧急情况时，立即按下急停并切断动力输出。
7. 运行期间与机器人保持安全距离，不要进入机械臂、轮组及其他运动部件的工作范围。
8. 不要将手、脚或身体其他部位置于关节、折叠机构、轮组等可能夹伤或挤压的区域。
9. 自主导航、遥操作或自动任务期间，确保周围人员知晓运行状态，避免进入规划路径。

## 通用安全守则

- **区域安全**：操作前确认工作区域内无人员或障碍物。
- **低速测试**：首次运行新程序或调整参数后，先低速测试。
- **紧急停止**：任何紧急情况下，立即使用红色物理急停按钮。
- **参数备份**：定期备份系统参数。
- **专业培训**：操作员须经过培训，熟悉操作流程和安全规范。
- **急停状态**：调试前确认急停已释放；急停按下时机器人不响应运动指令。
- **拖动示教**：进入拖动模式前确认周围安全，避免夹手。
- **电气安全**：不要在通电状态下插拔控制器线缆。
