## 后背控制面板

后背控制面板集中了电源输入、控制通信、数据传输和安全互锁接口。

| 接口 | 功能 |
| --- | --- |
| 急停按钮 | 蘑菇头自锁式急停开关，紧急情况下直接切断关键动作电源（硬件安全互锁）。按压触发，顺时针旋转复位 |
| 面板 Ethernet | RJ45 ×3，用于内部控制器交换、外部上位机通信或局域网数据交互。默认网段：RJ45 1 为 6.6.7.XX，RJ45 2 为 6.6.8.XX，RJ45 3 为 6.6.9.XX |
| USB 3.0 | Type-A ×4，用于外部存储、外设扩展或系统固件更新，最高 5 Gbps |
| 外部接口 | 多芯工业信号连接器，用于连接外部急停装置 |
| DM-485 | DB-9 RS-485 接口，连接关节模组伺服驱动（Debug 调试） |
| 面板电源 | 多芯工业电源接口，为整机供电 |

### 面板电源输出引脚

| 引脚 | 定义 | 功率 | 说明 |
| --- | --- | --- | --- |
| 1 / 7 | 48V / 0V | 200 W | 电池供电，48–60 V |
| 2 / 8 | 24V / 0V | 150 W | 24 V ±5% |
| 3 / 9 | 24V / 0V | 150 W | 24 V ±5% |
| 4 / 10 | 12V / 0V | 150 W | 12 V ±5% |
| 5 / 11 | 12V / 0V | 150 W | 12 V ±5% |
| 6 / 12 | 5V / 0V | 30 W | 5 V ±5% |

### 外部急停

出厂默认 1、4 引脚短接，3、6 引脚短接。如需外部急停，将 1、4 和 3、6 分别接入外部急停盒的常闭触点。

### DM-485 调试引脚

| 引脚 | 定义 | 用途 |
| --- | --- | --- |
| 1 / 2 | 485A / 485B | 左臂驱动调试 |
| 7 / 9 | 485A / 485B | 右臂驱动调试 |
| 8 / 5 | 485A / 485B | 头部和腰部调试 |

## 机械臂末端 8Pin 接口

| 引脚 | 定义 |
| --- | --- |
| 1 / 2 | DC24V 供电输出，额定电流 3 A |
| 3 / 4 | 485 通道 1 |
| 5 / 6 | 485 通道 2 |
| 7 / 8 | CAN，默认 CAN FD |

## 以太网架构

AGV 底盘控制器、激光雷达、天机运动控制计算平台和外部调试接口通过千兆以太网互联。

| 设备 | 作用 |
| --- | --- |
| NVIDIA Orin（标配） | 中央计算平台：AI 算法、多传感器融合、设备管理、网络调度 |
| 天机运动控制计算平台 | 躯干和双臂运动控制、外设管理；EtherCAT 主站 |
| RJ45 面板调试口 | 以太网调试与维护 |
| RDK S100 | AGV 底盘控制器 |
| AGV 内置交换机 | 底盘内部千兆以太网 |
| 前 / 后激光雷达 | 环境感知、定位建图、导航与避障 |

选装 NVIDIA Thor 时，Thor 作为整机智能计算中心，支持大模型推理（VLA）和多模态感知，并增加胸部交换机构建上半身内部网络。

## EtherCAT 架构

天机运动控制计算平台作为 EtherCAT 主站，统一管理全身关节驱动：

| 从站 | 说明 |
| --- | --- |
| M6 Left ×8 | 左臂 7 个关节驱动，第 8 个为末端 IO 板（配灵巧手时为 ×7） |
| M6 Right ×8 | 右臂 7 个关节驱动，第 8 个为末端 IO 板（配灵巧手时为 ×7） |
| Head Pitch | 头部俯仰 |
| Head Rotation | 头部旋转 |
| Waist Joint 1–6 | 腰部及腿部 6 个关节协同控制 |

## IP 地址

用网线连接面板 RJ45 1 即可访问以下设备：

| 设备 | IP 地址 | 作用 |
| --- | --- | --- |
| 底盘（RDK S100） | 6.6.7.6 | 底盘运动控制、状态反馈与系统管理 |
| 域控制器（Orin / Thor） | 6.6.7.100 | AI 算法、多传感器融合、设备管理与网络调度 |
| 运控控制器 | 6.6.7.190 | 躯干及双臂运动控制，EtherCAT 主站 |

将调试电脑设置为 6.6.7.x 网段（如 6.6.7.50），子网掩码 255.255.255.0。详细步骤见[连接用户电脑](../software/connect-pc.mdx)。

域控制器支持远程桌面登录。登录凭据随机器提供，请勿在共享文档中记录。
