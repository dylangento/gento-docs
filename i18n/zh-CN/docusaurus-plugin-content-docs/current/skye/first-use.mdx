Skye 装在木箱或航空箱中发运。开箱前请先准备好场地。

:::caution 重物
机器人及其包装较重，存在夹伤风险。请佩戴防护用品，小心搬运。
:::

## 准备场地

- **地面**：半径 2 m 范围内高差 ≤3 mm，静载承重 ≥300 kg/m²；无油污、积水、金属碎屑或高于 10 mm 的台阶。开箱前铺设纸板或缓冲垫，保护机器人外壳。
- **空间**：箱体四周预留 ≥800 mm 作业空间，正前方预留 ≥1000 mm 用于移出机器人；通道宽度 ≥1.2 m，层高须比机器人完全升起后的高度高出 500 mm 以上。
- **环境**：室内，0–45 °C，20–70 %RH，无凝露。不要在室外、潮湿、粉尘多或强电磁干扰的区域开箱，远离腐蚀性、易燃易爆物品。
- **安全**：隔离开箱作业区域，附近无高速运转设备，就近有电源插座，地面干燥防滑。

## 工具

| 必备 | 可选 |
| --- | --- |
| 美工刀、防滑劳保手套、撬棍、两用螺丝刀、卷尺、电工胶布、护目镜 | 手动液压搬运车、橡胶垫、毛刷、尖嘴钳、相机、记号笔 |

## 打开箱体

1. 检查箱体上的相关标签。
2. 找到箱体的 3 个锁扣。
3. 旋转锁扣解锁，然后打开箱体。

如发现零件缺失或损坏、型号与订单不符，或开箱遇到困难，请在机器人上电前联系 [Gento 技术支持](mailto:support@gentorobotics.ai)。

## 核对配置

对照订单检查机器人配置：

| 项目 | 配置 |
| --- | --- |
| AI 计算 | NVIDIA Jetson AGX Orin 64GB（标配）或 Jetson Thor T5000 1TB（选配） |
| 机械臂 | Marvin M6S CCS-696（标配）或选配机械臂，参见[机械臂选配](./overview.mdx#机械臂选配) |
| 头部相机 | RealSense D435 × 1，SHW5G 单目相机 × 2 |
| 腕部相机 | SHW5G 单目相机 × 2（标配）或 RealSense D405GA 深度相机 × 2（选配） |
| 末端执行器 | 天机夹爪、末端六维力传感器（选配） |
| 底盘 | 灵猴机器人 TX-S2 |
| 遥操作套件 | PICO Ultra（头显、手柄和 3 个动作追踪器）及 GameSir 体感手柄 |

## 调平并检查稳定性

1. 用水平仪调平底盘，整机水平误差控制在 0.5° 以内，防止运行时倾斜或重心偏移。
2. 机器人静止时，用手轻推机身，确认不滑动、不翘起。
3. 空载低速运行，确认机身不移位、无异响。

## 每次启动前检查

1. 机器人各部件完好，无损坏或松动。
2. 急停按钮功能正常。
3. 无线终端无报警信息。
4. 未加装未经授权的配件或设备。
5. 机器人工作范围内无人员。

## 回装存储或运输

| 步骤 | 操作 |
| --- | --- |
| 1. 设备准备 | 断电；拆下电源线、通信线、夹板等外部附件。清洁机身灰尘和污渍，将双臂和升降立柱恢复到运输/存储姿态 |
| 2. 恢复运输固定 | 装回出厂运输夹块和扎带，锁定底盘刹车，防止运输中移动 |
| 3. 恢复防护包装 | 在机身关键部位套上泡棉，并用保护膜包裹，避免刮伤漆面 |
| 4. 收纳附件 | 将控制器、线缆、急停按钮和纸质资料统一放入附件袋或附件仓 |
| 5. 装箱固定 | 将机器人平稳移入木箱，用缓冲泡棉填充四周空隙，拧紧箱体螺钉并打上钢带 |
| 6. 保留标签 | 保留外包装出厂标签并完整封箱。短期存放时注意防潮，箱上不要压放重物 |

长途运输时请使用官方航空箱或木箱，用木板、泡棉和绑带固定机器人，避免剧烈颠簸。搬运前务必关闭机器人电源。
