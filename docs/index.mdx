## Before you begin

Every robot connects to your PC the same way. Start with [Connect your PC](./software/connect-pc.mdx) to set up the cable, IP address, and firewall.

Check the robot model, controller version, and installed software. Instructions and configuration files are version-specific. For Marvin Pro, start with [compatibility](./marvin-pro/compatibility.mdx) if you are unsure which guide applies.

If the English and Chinese versions differ, the Chinese version applies. Contact [Gento support](mailto:support@gentorobotics.ai) if anything is unclear.

## Product documentation

These docs cover Marvin Pro, Marvin, and Luna. Skye documentation is coming soon. The shared Software & development and Teleoperation sections were written for Marvin Pro; Luna has its own software and SDK pages.
