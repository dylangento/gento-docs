Treat mechanical mounting, power, communication, and software integration as separate checks. A flange adapter alone does not establish complete teleoperation or data-recording support.

## Integration checklist

| Area | Confirm for the exact tool |
| --- | --- |
| Mechanical | Flange drawing, adapter, fasteners, tool envelope, and cable clearance |
| Electrical | Voltage, current, connector pinout, and external supply requirements |
| Communication | Device protocol, bus configuration, and matching driver |
| Dynamics | Tool mass, center of mass, and inertia configuration |
| Control | Command mapping, limits, and handover behavior |
| Recording | Available signals, timestamps, and synchronization |

## Tool dynamics

The Pro manual describes collecting no-load and loaded trajectories, calculating tool mass, center of mass, and inertia, then applying the tool parameters. These procedures cause motion and require the correct arm configuration and identification trajectory. They are not part of the beginner setup sequence.

Wrist supply voltage depends on the arm configuration, so don't take it from a generic product table. Confirm your arm's electrical interface before attaching a hand or camera.
