<p className="doc-lead">Skye documentation is in progress.</p>

Gento Skye is a wheeled lifting robot: a humanoid development platform with whole-body force control and open control access, built for embodied AI, reinforcement learning, and real-world validation. Platform-level motion control and planning (the "cerebellum") come ready, so developers can focus on models and algorithms.

![Gento Skye in a warehouse](/img/skye/warehouse.webp)

## What's coming

Skye documentation will follow the same structure as Marvin Pro, Marvin, and Luna:

- Product overview and specifications
- Unboxing, installation, and first use
- Interfaces, network, and communication architecture
- Host software, SDK, and teleoperation
- Troubleshooting, maintenance, and safety

## Need help now?

Skye shares the [Gento series SDK repository](https://github.com/tianjizn/tianji-robot-SDK/tree/Gento_Skye+Luna) with Luna. For Skye documents or support, contact [support@gentorobotics.ai](mailto:support@gentorobotics.ai).
