Marvin Platform is the desktop interface for configuring the robot, monitoring feedback, and using the controller's motion functions. The September Chinese software guide describes Linux x86 and Windows 64-bit support.

## Build selection in the source guide

| Controller label in guide | Windows script | Ubuntu script |
| --- | --- | --- |
| “41” | `marvinSDK_windows.bat` | `marvinSDK_ubuntu.sh` |
| “43” | `marvinSDK_windows_100343.bat` | `marvinSDK_ubuntu_100343.sh` |

The guide names `ui_EN.py` as the application entry point after the SDK is built. Before using these scripts, [check the controller firmware version](./cameras-firmware.mdx), [identify your arm model and set up its configuration files](./sdk-quickstart.mdx), and confirm the repository revision. See [SDK quick start](./sdk-quickstart.mdx).

## Run Marvin Platform on Linux

Marvin Platform needs Python 3.10 or later and Pillow (`pip install pillow`). From the SDK's root folder:

1. Build the libraries. This compiles `libMarvinSDK.so` and `libKine.so` and copies them into `SDK_PYTHON` and `DEMO_C++`. For a "41" controller, use `marvinSDK_ubuntu.sh` instead.

   ```bash
   chmod +x marvinSDK_ubuntu_100343.sh
   ./marvinSDK_ubuntu_100343.sh
   ```

2. Install the Microsoft core fonts. Marvin Platform uses Arial, and without it `ui_EN.py` stops with a TrueType font error. Accept the font license when the installer asks.

   ```bash
   sudo apt install ttf-mscorefonts-installer
   ```

3. Start Marvin Platform:

   ```bash
   cd MarvinPlatform_EN
   python3 ui_EN.py
   ```

| Message | Fix |
| --- | --- |
| A TrueType font error when `ui_EN.py` starts | Install the fonts (step 2), then run `ui_EN.py` again. |
| `No module named 'tkinter'` | `sudo apt install python3-tk` |
| `No module named 'PIL'` | `pip install pillow` |

## Feedback fields

![Marvin Platform feedback interface](/img/marvin-pro/platform-feedback.webp)

| Field | Meaning in the software guide |
| --- | --- |
| Position | Joint angle derived from the motor-side encoder |
| Velocity | Joint velocity |
| Torque | Torque-sensor feedback |
| Current | Thousandths of the joint's rated current |
| Temperature | Temperature; the Pro manual notes version-dependent use of this field |
| PositionEX | Joint angle derived from the output-side encoder |
| CmdPosition | Commanded joint position |
| ForceEST | Estimated external joint load |

Torque-sensor feedback and estimated external load are separate values. Current is not presented as amperes in this interface. Confirm units and message definitions in the SDK before recording or controlling from these fields.
