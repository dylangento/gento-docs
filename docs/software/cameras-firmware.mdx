Routine jobs you run from your PC over the network. First [connect your PC to the robot](./connect-pc.mdx) and check that the robot answers a ping.

`ssh` works in PowerShell on Windows 10/11 and in any Ubuntu terminal. The first time you connect to a robot, type `yes` to trust it.

## Connect to the Orin or Thor

On Marvin Pro, Luna, and Skye, the AI controller (NVIDIA Orin or Thor) is at `6.6.7.100`. Log in as `nvidia`, using the password supplied with your robot.

- **Terminal:** `ssh nvidia@6.6.7.100`
- **Remote desktop:** connect to `6.6.7.100` with [NoMachine](https://www.nomachine.com/download).

### Use NoMachine without a monitor

If no monitor is plugged into the Orin or Thor, NoMachine shows a black screen. To connect without a monitor, log in over SSH and run:

```bash
sudo systemctl stop display-manager
sudo /etc/NX/nxserver --restart
```

Then connect with NoMachine again. This lasts until the Orin or Thor restarts, so run it again after each power-up.

## Start the cameras

On robots with onboard AI compute (NVIDIA Orin or Thor), start the cameras after every power-up, before you teleoperate or record data.

1. Log in to the AI controller, using the password supplied with your robot:

   ```bash
   ssh nvidia@6.6.7.100
   ```

2. Start the cameras:

   ```bash
   cd /home/camera/cam_geac
   ./rb_camera.sh init
   ```

3. Wait about 20 seconds for the cameras to come up, then type `exit`.

## Check the controller firmware version

The x86 motion controller prints its firmware version when its control service starts. You need it to choose the matching [Marvin Platform build script and SDK](../marvin-pro/compatibility.mdx).

:::warning This restarts the motion controller
`stop.sh` stops the controller. Before you run it, disable the arms, make sure no software is commanding the robot, and keep the E-stop within reach.
:::

1. Log in to the x86 controller as `root`. The password is `passwd`.

   | Robot | Command |
   | --- | --- |
   | Marvin Pro, Luna, Skye | `ssh root@6.6.7.190` |
   | Marvin | `ssh root@192.168.1.190` |

2. Restart the control service:

   ```bash
   cd /home/FUSION/Shell
   ./stop.sh
   ./start.sh
   ```

3. `start.sh` prints the firmware version. Write it down, then type `exit`.

## If you can't log in

| Message | What to check |
| --- | --- |
| `Connection timed out` or `No route to host` | Your PC isn't on the robot's network. See [Connect your PC](./connect-pc.mdx). |
| `Permission denied` | The user name or password is wrong. Use `nvidia` for the Orin/Thor and `root` for the x86 controller. |
| NoMachine shows a black screen | No monitor is plugged into the Orin or Thor. See [Use NoMachine without a monitor](#use-nomachine-without-a-monitor). |
| `REMOTE HOST IDENTIFICATION HAS CHANGED` | You've connected to a different robot at the same address before. Run `ssh-keygen -R 6.6.7.100` (or the address you used), then connect again. |
