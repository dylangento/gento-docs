Software, SDKs, and documentation for Gento robots. Each entry lists the guide it comes from and the platform it applies to, so you can pick the package that matches your controller.

| Resource | Purpose / platform | Source & compatibility | Repository or documentation |
| --- | --- | --- | --- |
| Marvin Platform / motion SDK | Windows 64-bit and Linux x86; robot control and configuration | September 2026 guide; select controller-specific build | [TJ_FX_ROBOT_CONTRL_SDK · master](https://github.com/cynthia-you/TJ_FX_ROBOT_CONTRL_SDK/tree/master) |
| Apex robot packages | ARM64 NVIDIA Jetson; robot-side teleoperation services | September 4, 2026 resource guide | [KernelMind_Apex_Deb](https://github.com/Gento-Teleoperation-Apex/KernelMind_Apex_Deb) |
| Apex desktop application | Operator computer | Choose the matching OS/release | [KernelMind_Apex_Web_Deb](https://github.com/Gento-Teleoperation-Apex/KernelMind_Apex_Web_Deb) |
| Apex VR APK | VR headset client | Match headset and robot-side release | [KernelMind_Apex_VR_Apk](https://github.com/Gento-Teleoperation-Apex/KernelMind_Apex_VR_Apk) |
| Apex documentation | Installation, ROS 2 interfaces, recording, converter | Select Marvin Pro and the installed release | [Apex documentation center](https://gento-teleoperation-apex.github.io/Apex_doc_center/) |

Check that a release matches your robot before you install it. The Pro V1.0 manual also refers to the upstream [KLMmotion release repository](https://github.com/KLMmotion/KernelMind_Apex_Deb/releases); the later VR resource guide points to the Gento repositories above.

For first-time development, read [SDK quick start](./sdk-quickstart.mdx). For deployment order, read [Apex installation](../teleoperation/setup.mdx).
